CSS Nedir?

CSS, web sayfalarının görünümünü ve kullanıcıya nasıl sunulacağını belirleyen stil dilidir.

🎨

CSS

Cascading Style Sheets yani Basamaklı Stil Şablonları, HTML ile oluşturulan yapıların görsel olarak biçimlendirilmesini sağlar.

🧱

HTML + CSS

HTML sayfanın yapısını oluştururken CSS renk, yazı tipi, boşluk, boyut ve yerleşim gibi görsel özellikleri düzenler.

✨

Tasarım

CSS sayesinde sade HTML yapıları modern, responsive, hareketli ve kullanıcı dostu arayüzlere dönüştürülebilir.

Basit Bir CSS Örneği

h1 {
    color: blue;
    font-size: 40px;
}
Bu başlık CSS ile biçimlendirilmiştir.
CSS'in temel mantığı: HTML yapıyı oluşturur, CSS ise bu yapının nasıl görüneceğini belirler.
