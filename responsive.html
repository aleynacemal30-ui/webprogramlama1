Responsive Tasarım

Responsive tasarım sayesinde web siteleri farklı ekran boyutlarına uyum sağlayabilir.

DESKTOP

Esnek Tasarım

Aynı web sitesi bilgisayar, tablet ve telefon ekranlarında farklı ölçülere uyum sağlayabilir.

Media Query

@media (max-width: 768px) {

    .cards {
        grid-template-columns: 1fr;
    }

    h1 {
        font-size: 40px;
    }

}
