BEM & Sass / SCSS

Büyük CSS projelerinde düzenli ve sürdürülebilir kod yapıları oluşturmak önemlidir.

B

BEM

BEM, CSS sınıflarını daha düzenli ve anlaşılır şekilde isimlendirmek için kullanılan bir yöntemdir. 

.card {}
.card__title {}
.card--large {}
S

Sass / SCSS

CSS yazımını daha düzenli hale getirmek için değişkenler, nesting ve benzeri özellikler kullanılabilir. 

$main-color: purple;

.button {
    color: $main-color;

    &:hover {
        opacity: .8;
    }
}
Düzenli isimlendirme ve yapılandırılmış CSS, büyük projelerin yönetilmesini kolaylaştırır.
