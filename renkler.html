Renkler & CSS Değişkenleri

CSS renkleri ve değişkenleri kullanarak tutarlı ve yönetilebilir tasarımlar oluşturabiliriz.

#24D6A3 Yeşil
#FF5C8A Pembe

CSS Değişkenleri

:root {
    --main-color: #7c5cff;
    --background: #0b1020;
    --text: #ffffff;
}

.button {
    background: var(--main-color);
    color: var(--text);
}
