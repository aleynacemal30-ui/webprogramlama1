CSS Anatomisi

Bir CSS kuralının selector, property ve value olmak üzere temel parçalarını inceleyelim.

CSS Kuralının Yapısı

h1 {
    color: red;
    font-size: 40px;
}

Selector

Hangi HTML elementinin seçileceğini belirtir.

h1

Property

Element üzerinde hangi özelliğin değiştirileceğini belirtir.

color

Value

Seçilen özelliğin alacağı değeri belirtir.

red

CSS Ekleme Yöntemleri

1

Inline CSS

CSS doğrudan HTML etiketi içerisinde yazılır.

<p style="color:red;">
    Merhaba
</p>
2

Internal CSS

CSS, HTML dosyasındaki style etiketi içerisinde yazılır.

<style>
    p {
        color: red;
    }
</style>
3

External CSS

CSS ayrı bir dosyada tutulur.

<link
rel="stylesheet"
href="style.css">
