Pseudo-classes & Elements

Kullanıcının etkileşimlerine veya elementlerin belirli durumlarına göre stil değiştirebiliriz.

Butonun Üzerine Gel 👇

:hover Örneği

button {
    background: purple;
}

button:hover {
    transform: scale(1.08);
}

:hover

Kullanıcı mouse ile elementin üzerine geldiğinde uygulanır.

:focus

Bir form elementi odaklandığında kullanılabilir.

:active

Element aktif durumdayken stil uygulanmasını sağlar.

::before

Elementin içeriğinin öncesine görsel içerik eklemek için kullanılabilir.
