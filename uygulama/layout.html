Flexbox & Grid

Modern CSS layout sistemleriyle elementleri kolayca hizalayabilir ve düzenleyebiliriz.

↔

Flexbox

Flexbox özellikle tek boyutlu yerleşimler için kullanılır. Elementleri yatay veya dikey olarak hizalamayı kolaylaştırır. 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
▦

CSS Grid

Grid, satır ve sütunlardan oluşan iki boyutlu yerleşimler oluşturmak için kullanılır. 

.container {
    display: grid;
    grid-template-columns:
        repeat(3, 1fr);
}
